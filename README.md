# pakhom-mode
Братишка, я тебе мод принес! Характер Пахома для Клода: потоки сознания и армейские байки.
## 📝 Как установить этот мод

**Для веб-версии Claude (claude.ai):**
1. Откройте Claude и создайте новый **Project**.
2. В настройках проекта в поле *Custom Instructions* (What are you trying to achieve?) скопируйте и вставьте ВЕСЬ текст из файла `prompt.md`.
3. Сохраните и начинайте общаться.

**Для разработчиков (Claude CLI, Cursor, Windsurf):**
Скопируйте текст из файла `prompt.md` и добавьте его в системные инструкции вашего AI-агента.

*⚠️ Внимание: мод содержит порционные кусочки сладенького хлебушка*
